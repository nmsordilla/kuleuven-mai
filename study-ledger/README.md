# MAI Study Ledger

A weekly study-hour tracker for the KU Leuven Master of Artificial Intelligence (ECS), 2026–2027.

Each course's budget is ECTS × hours per credit (25–30 h, default 27.5). The page spreads that budget evenly over the course's semester and compares it with the hours you log each week. Scheduled lectures and exercise sessions from the TimeEdit timetable are shown in each day's cell, and one button logs the classes you attended.

Live page: https://claude.ai/artifact/1uncUj7S4EnqjGHTxs4mMQ (private; hours are saved to your claude.ai account).

## Files

| File | What it is |
|---|---|
| `ledger.html` | The page. It is published as a claude.ai artifact, which adds the `<!doctype>`/`<head>` skeleton. |
| `schedule.json` | Courses from the ISP, the semester calendar, and every class session for this programme's courses. Generated by the script below; don't edit it by hand. |
| `tools/build-schedule.mjs` | Source of `schedule.json`. It has the session tables taken from the TimeEdit export of 2026-10-11. |
| `tools/serve.mjs` | A local preview server. Use it rather than a generic static server; see below. |

## Previewing locally

```sh
node study-ledger/tools/serve.mjs      # then open http://localhost:8000/
```

`ledger.html` has no `<head>` of its own — the artifact runtime adds the
`<!doctype>`/`<head>` skeleton, `<meta charset="utf-8">` included. A generic
static server (`python3 -m http.server`, say) sends `text/html` with no charset,
so the browser falls back to windows-1252 and the page fills with mojibake
(`·` shows as `Â·`). `tools/serve.mjs` names the charset, so it renders the way
the published artifact does.

## Updating the timetable

Edit the tables in `tools/build-schedule.mjs`, then rebuild:

```sh
node study-ledger/tools/build-schedule.mjs
```

Then republish `ledger.html` together with `schedule.json` to the same artifact URL.

## Notes

- The exam period end dates (31 Jan 2027 and 4 Jul 2027) are estimates. You can change them in the page's Plan settings.
- Exercise groups default to group A. Pick your real group for each course in Plan settings.
- When it runs outside claude.ai, the page falls back to browser storage, so hours logged in a local preview are separate from the ones on the artifact. It needs to be served over HTTP so it can fetch `schedule.json`, so opening it with `file://` won't work.
